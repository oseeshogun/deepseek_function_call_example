# Code of Conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
The full text at that link applies to everyone who takes part in the project.

In short:

- Be respectful and welcoming, whatever someone's background or experience.
- Give and accept constructive feedback gracefully.
- Focus on what is best for the project and the people using it.
- Harassment, insults, discrimination and personal attacks are not accepted.

## Reporting

If you experience or witness unacceptable behavior, report it privately to the
maintainer through their GitHub profile,
[@oseeshogun](https://github.com/oseeshogun). Reports are handled
confidentially.

Maintainers may remove comments, commits, issues or contributions that break
this code, and may ban contributors who do so repeatedly.
